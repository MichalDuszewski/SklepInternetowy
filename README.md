# README - SklepInternetowy
[Polski](#polski) | [English](#english)

### Polski
## Opis

Sklep Internetowy to strona internetowa stworzona całkowicie przeze mnie przy użyciu PHP i bazy danych MySQL. Operacje na bazie danych wykonowane są za pomocą samodzielnie stworzonych endpointów REST API. Oprawa wizualna stworzona przy wykorzystaniu framoworku Boostrap.

### English
## Description

Sklep Internetowy is a website I built entirely on my own using PHP and a MySQL database. Database operations are performed using custom REST API endpoints. Visual design was created using the Bootstrap framework.
